Le projet

Website Uptime Monitor, un systeme de surveillance construit sur AWS.

Ce projet surveille automatiquement la disponibilite de ce site. Trois fonctions Lambda tournent toutes les 5 minutes et verifient chacune un point different: le site se charge-t-il, en combien de temps, et affiche-t-il le bon contenu.

Des qu'un des trois checks echoue, une notification part immediatement par SNS (email et SMS), avec le detail de l'erreur. Chaque resultat, succes ou echec, est aussi enregistre dans DynamoDB avec un horodatage et le temps de reponse, pour garder un historique complet.

Toutes les heures, une quatrieme Lambda agrege cet historique en quelques metriques (disponibilite, latence moyenne, echecs par type) et les publie sur un dashboard statique heberge sur S3.

  • Lambda + EventBridge pour les checks planifies
  • SNS pour les alertes
  • DynamoDB pour l'historique
  • S3 pour ce site et pour le dashboard
